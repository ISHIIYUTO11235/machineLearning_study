# machineLearning_study

機械学習の学習記録用リポジトリ。旧東京工業大学（岡崎研究室）が無料公開している教材 [機械学習帳](https://chokkan.github.io/mlnote/index.html) を題材に、各トピックを手を動かしながら学んだ過程をまとめています。

## 概要

教材を読むだけでなく、アルゴリズムを自分で実装・可視化しながら理解を深めることを目的とした学習リポジトリです。

## 内容

- 機械学習の基礎トピック（回帰・分類・最適化など）の実装と実験ノート
- 数式を実際のコードに落とし込みながら挙動を確認

## 使用技術

- **言語**: Python
- **教材**: 機械学習帳（chokkan.github.io/mlnote）

> 学習の記録を目的としたリポジトリです。
